# Labs — исполняемые прототипы

**Статус: экспериментов и кода здесь пока нет.**

`labs/` предназначен для технических проверок гипотез из [research/](../research/README.md). Каждый lab должен ссылаться на протокол, фиксировать зависимости, шаги запуска, исходные данные и фактические результаты.

Экспериментальный код не считается production-кодом. Не интегрировать результаты экспериментов в `apps/` без явной оценки, решения и тестов. CI для labs будет определяться отдельно, не как автоматический product release.
