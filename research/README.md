# Research — исследования PACT

Здесь хранятся исходные материалы, сравнения альтернатив, гипотезы, протоколы и результаты экспериментов; исследование **не равно** принятому архитектурному решению.

## Принципы

- **Проблема и домен → гипотеза → эксперимент → evidence → решение.** Не начинаем с технологической моды.
- Указываем **дату**, первоисточники/ссылки, наблюдаемые факты, интерпретации, альтернативные объяснения и нерешённые вопросы.
- Отмечаем достоверность и актуальность: `confirmed / partial / assumed / disputed` по смыслу конкретного утверждения.
- Гипотезы об универсальном ядре проверяем хотя бы на **кофейнях и рыбных фермах УЗВ** либо явно описываем, почему проверка пока не выполнена.
- Результаты экспериментов отделяем от протоколов. Пустая запись без выполнения не является доказательством.
- Не помещаем сюда приватные данные пилотных партнёров и не воспроизводим материалы, на которые нет прав.

## Текущие гипотезы и планы экспериментов

- [Operational ontology / digital model as PACT foundation](hypotheses/ontology-operational-value.md) — проверяемая альтернатива «единая операционная модель» vs «domain model + integrations + rules + UI», включая независимую симуляцию, data quality, evidence, контрольный домен УЗВ. **Статус: Hypothesis / planned experiment, не выполнен.**
- [Предлагаемые границы RAT 1.0](../docs/product/rat-1.0-scope.md) и [RAT → MVP roadmap](../docs/product/mvp-roadmap.md) — продуктовый контекст, не подтверждённые результаты.

- [Video as contextual evidence — варианты и ограничения](video-evidence/approaches.md) и [optional feasibility protocol](video-evidence/feasibility-protocol.md) — короткое видео из архива по временному окну события (ориентир 100×100, 3 FPS), **без CV/action recognition**; необязательная демонстрационная функция RAT, не выполнена.
