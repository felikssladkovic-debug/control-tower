# Product

**Статус:** продуктовые ориентиры и исследования (Proposed), не подтверждённые требования и не реализованный функционал.

Первый предполагаемый пилот — действующие кофейни в Гане, интеграция с существующими POS, оборудованием и процессами. Пользовательские проблемы, фактическая готовность партнёров, экономические показатели и критерии успеха требуют отдельной верификации.

## Предлагаемые продуктовые границы

- [RAT 1.0 — Scope / Riskiest Assumptions Test](rat-1.0-scope.md) — три **виртуальные** кофейни, POS + кофемашина, три напитка, два сценария инцидентов, три ролевые рабочие области, независимый симулятор, evidence и критерии проверки. **Proposed; эксперимент не выполнен.**
- [RAT → MVP 1.0 → MVP 2.0](mvp-roadmap.md) — разделение проверки архитектурных гипотез, реального пилота и тиражирования; функции MVP 2.0 являются кандидатами, а не утверждённым backlog. **Proposed; реальные пилоты не подтверждены.**
- [Гипотезы об операционной модели и план сравнения альтернатив](../../research/hypotheses/ontology-operational-value.md) — сравнение с традиционной domain model + integrations + rules + UI и контрпример УЗВ. **Hypothesis / planned experiment.**

## Принципы

- Не путать **Vision**, **Hypothesis**, **Decision**, **Implementation** и evidence.
- **Observe → Understand → Decide → Act → Verify** — проверяемый ориентир; отчёт симулятора не доказывает пользу для бизнеса.
- Продуктовая гипотеза «общая модель» не является решением внедрить универсальную метамодель или графовую БД.
- Выбор следующего этапа зависит от результатов RAT/пилота, а не от предварительного списка функций.

Будущие артефакты: проблемные интервью, personas/roles, jobs to be done, use cases, измеримые baseline и benefits, операционные ограничения, UX-гипотезы, измерения пилота.

Ни одна доменная функция не считается принятой к реализации без исследования потребности и критериев приёмки. Подготовка технического bootstrap **не доказывает** коммерческую ценность PACT.
